# 2026 AAOP / Chronic Orofacial Pain HTML Archive

このリポジトリは、`2026TMD.mp4` から作成した静的HTML資料です。

## Contents

- `index.html` - 全体概要
- `video-lecture-guide.html` - 動画と切り出し画像を合わせた完全解説版
- `aaop-report.html` - AAOP 50周年記念学術大会の参加報告
- `chronic-orofacial-pain.html` - 慢性口腔顔面痛への私見と論文URL
- `assets/images/` - 動画から切り出した掲載用画像
- `assets/css/style.css` - 表示スタイル

## Notes

- 原動画 `2026TMD.mp4` はサイズが大きく、個人情報や参加者画面を含むため、このリポジトリには含めません。
- 本資料は動画画面・スライド・関連論文検索から作成した解説であり、逐語録ではありません。
- GitHub Pages で公開する場合、非公開リポジトリの Pages 可否は GitHub のプラン設定に依存します。非公開のまま共有する場合は、リポジトリまたは特定ユーザーへのアクセス権で管理してください。
