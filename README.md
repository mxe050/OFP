# OFP 予備室

口腔顔面痛・BMSに関する専門家議論と講義録をまとめた、独立したパスワード保護アプリです。

## 開発

```bash
npm ci
npm run dev
```

## ビルド

```bash
npm run build
```

ビルド成果物は `dist/` に出力されます。

## 移植資料

- `public/aaop2026/` - 2026年AAOP総会講演録・和嶋先生慢性疼痛

## HTMLを直接開く場合

`index.html` をダブルクリックすると、独立版の「予備室（パスワード）」が表示されます。パスワード解除後に、元の予備室1・予備室2の本文と「2026年AAOP総会講演録・和嶋先生慢性疼痛」へのリンクを開けます。

動画本体は Git 管理対象外で、このHTMLアプリには動画プレイヤーを置いていません。講演内容は切り出し画像と解説本文で読める構成にしています。
