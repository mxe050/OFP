# OFP 予備室

口腔顔面痛・BMSに関する専門家議論と講義録をまとめた、独立したパスワード保護アプリです。

## 開発

```bash
npm ci
npm run dev
```

## ビルド

```bash
npm run build
```

ビルド成果物は `dist/` に出力されます。

## 移植資料

- `public/aaop2026/` - 2026年AAOP総会講演録・和嶋先生慢性疼痛

## HTMLを直接開く場合

`index.html` をダブルクリックすると、独立版の「予備室（パスワード）」が表示されます。パスワード解除後に「2026年AAOP総会講演録・和嶋先生慢性疼痛」を開けます。

動画本体 `2026TMD.mp4` は大容量のため Git 管理対象外です。ローカルで `OFP/2026TMD.mp4` がある場合、完全解説版ページ内の動画プレイヤーから再生できます。
